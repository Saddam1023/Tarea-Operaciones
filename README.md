# Tarea-Operaciones
Descripción del proyecto

Este proyecto consiste en el desarrollo de una calculadora básica utilizando el lenguaje de programación Python. Su objetivo es aplicar los conceptos de funciones, módulos, importación de archivos y estructuras condicionales.

El programa permite realizar cuatro operaciones matemáticas: suma, resta, multiplicación y división.

Funcionalidades

Sumar dos números.

Restar dos números.

Multiplicar dos números.

Dividir dos números.

Validar la división entre cero.

Mostrar los resultados en pantalla.

Permitir al usuario seleccionar una operación mediante un menú.

Estructura del proyecto

El proyecto está compuesto por dos archivos principales:

Operaciones.py: contiene las funciones matemáticas sumar(), restar(), multiplicar() y dividir().

main.py: importa el módulo Operaciones, solicita dos números al usuario, presenta el menú de operaciones y muestra el resultado.

Requisitos

Python 3 instalado.

No requiere librerías externas.

Ejecución del programa

Descargar o clonar el repositorio.

Abrir la carpeta del proyecto.

Ejecutar el archivo principal con el comando:

python main.py

Ingresar dos números.

Seleccionar la operación deseada.

Visualizar el resultado en pantalla.

Ejemplo de funcionamiento

=== CALCULADORA BASICA ===

Ingrese el primer numero: 10
Ingrese el segundo numero: 5

Seleccione una operacion:
1. Suma
2. Resta
3. Multiplicacion
4. Division

Ingrese una opcion (1-4): 1
Resultado: 15.0

Manejo de errores

El programa incluye validaciones para evitar errores cuando el usuario ingresa valores no numéricos, selecciona una opción inválida o intenta dividir entre cero.
